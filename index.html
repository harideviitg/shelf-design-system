Introduction

A small sub heading or explanation about this tab

Bracket is the design system behind Shelf, the context engine for people who work alongside AI tools. It gives every Shelf surface, from the capture sheet to the item page to the handoff, one accessible, consistent visual language.

Shelf lives on the phone first and the browser second, so every token here is defined once and consumed twice: SwiftUI on iOS, CSS custom properties on the web. Nothing on this page is a redraw. The values were read out of the Figma file’s node JSON rather than measured off a render, and where the file is silent the page says so instead of guessing.
